# 日版 1.40：独立简体中文选项的离线闭环

2026-11-13，Windows。原厂日版 `705J140.dat` 的 PC 仿真面板已验证：点选第三项「简体中文」→ 用原厂设置例程保存 → 新 ARM 实例重读 → 「显示设置」仍为中文、第三行仍选中。简体、英语、日语分别保存为 `02/00/01`，全程没有改变日语系统设置 `01`。

双击 [Open-IC705-Third-Language.cmd](../Open-IC705-Third-Language.cmd)。首次打开时，点 `MENU`、`SET`，到「セット」第 2 页进入「ディスプレイ設定」，第 6 页打开「表示言語」。选「简体中文」，再点窗口底部的「保存」。关闭窗口并重新双击，面板从首页打开，之后路径为「菜单 → 设置 → 显示设置 → 显示语言」。面板会记住之前的页码，若已在第 2 或第 6 页，可直接点对应的行。

2026-11-14：使用两个独立的 Windows 预览进程实际测试。第一个进程从日语首页点选中文并保存；第二个进程重开后显示「菜单」，语言选择页的「简体中文」仍高亮，系统语言仍为日语。设置只保存在本机 `.analysis/ic705-emulator/j140-third-build/pc-display-settings.bin`；它既不是原厂设置导出，也不是可用于电台的固件。首次打开预览仍由电脑将原厂面板放到首页，没有验证从通电自然进入首页。

本次解决了三个具体问题：

1. 只在 Unicorn RAM 内修改 `0xA7` 的选项上限与选项表指针。原厂按每组 `max+1` 项索引，所以分别为日文和英文复制原来的两项并添加第三个标签。`0xA8` 及其使用的原表不变。原厂菜单创建、触摸命中和提交沿用同一套代码。
2. 发现仅让界面打包把 `2` 映射成日语仍不够：重读后，显示设置第一页的「LCD バックライト」原厂标签没有进入绘制。把原厂语言函数返回给旧调用方的 `2` 在模拟 RAM 中兼容映射为 `1`，同时保留独立中文状态和原始存储值 `2`；同一回放随后恢复该行。原厂系统语言为英语时，原函数仍返回 `0`，没有中文输出。
3. 复用原有 UTF-16 词表和 FreeType 内存字库。第三项标签在日英列表中也能画成「简体中文」；其余翻译只在独立中文状态启用。未覆盖的文字沿用日语原文，系统语言项目也保留原厂日语文字。输出仍由原厂 ARM 绘图代码和 PC 图形后端生成。

导航补充：ARM 在改写待绘字符串前，用固件中的 FreeType 字形查询（`0x2025B668`）逐字检查；未找到任一字形时保留整条原文和原字体。第三项没有原厂对应项，因此给它提供英文备选。右下 `SET` 则是嵌字位图：原图位于映射地址 `0x189ED180`，可见宽 90 像素、高 90、每行存储 96 像素（BGRA）。PC 图形后端先核对原图哈希，只在字形齐全、中文生效时复制原图并替换底部文字；ARM 图块坐标和触摸处理都沿用原厂。图块替换尚未在原厂 ARM 图形代码内实现。

[原厂基准实验](IC705_LANGUAGE_PERSISTENCE.md)记录没有这些仿真接入时的表现；[REA 复核](REA_ANALYSIS.md#j140-独立显示语言试验)记录选项表和兼容层位置。固件源文件未改动，未生成刷机包或连接电台。词表、代码和字库由 PC 装入仿真 RAM；还没有原厂冷启动自动加载扩展的证据。

## 复现

复用 [已有的 Python、Arm GNU 工具链和 Noto 字体](IC705_ZH_CATALOG.md#复现)：

```powershell
$env:PYTHONPATH = (Resolve-Path .analysis/ic705-emulator/deps).Path
py -3.14 -X utf8 -m tools.virtual_705_display_catalog firmware/705J140.dat --third-language --replay .analysis/ic705-emulator/j140-zh-navigation
py -3.14 -X utf8 -m tools.check_705_chinese_restart firmware/705J140.dat .analysis/zh-cn-preview/noto/NotoSansSC-VF.ttf .analysis/ic705-emulator/j140-chinese-restart-rerun
```

本次输出 21 张 PNG 和 `third-language.json`，含原厂触摸、模拟存储读写、文字、画面哈希、图块像素差异范围及两条恢复记录。17 组正常画面与同状态的原厂画面逐像素一致；英语回退重读为 `00/01`，日语回退重读为 `01/01`。原有 103 帧词表回放、原厂保存回放和 36 项单元测试也通过。原厂 DAT 的 SHA-256 不变：`2522f62211ad5fdb313e793f94bb0574a22327660bdbde47ba9124f424114e45`。

[J140 字库回放](IC705_SD_RESOURCES.md#j140从字库发现到首条测试菜单绘制)已验证原厂 ARM 从模拟 Flash 的固定记录加载开源字库，并能绘制原字体缺失的简体字。[资源函数分支对照](IC705_SD_RESOURCES.md#j140资源函数入口与标签分支)验证了标签不匹配不会跳过字体读取；入口与后段尚未连通。优先从「表示言語」原厂记录验证转换前的文案接入，再以显示语言和系统语言做回归。在扩大词表前，用原厂可变数值和单位测试最长文字、数字混排与缺字回退。
