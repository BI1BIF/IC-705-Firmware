# 日版 1.40：原厂「显示设置」六页汉化回放

## 复现

使用已有 Arm GNU Toolchain、Python 3.14、Unicorn 2.1.4、Pillow 和 fontTools。源字体沿用 [Noto Sans SC 固定版本和许可证](IC705_ZH_CN_PAGE.md#来源和复跑)。启动器在 `.analysis/` 内构建字体子集和 ARM 代码。目录 `.analysis/` 和原厂文件由 Git 忽略。

```powershell
$env:PYTHONPATH = (Resolve-Path .analysis/ic705-emulator/deps).Path
py -3.14 -X utf8 -m tools.virtual_705_display_catalog firmware/705J140.dat --replay .analysis/ic705-emulator/j140-display-catalog
py -3.14 -X utf8 -m unittest discover -s tests
```

输出的 `trace.json` 记录触区、菜单和写入；`stock/`、`zh/` 可直接对照 480×272 图像。优先查看 `display-3-98-options-1.png`、`display-3-98-30-seconds.png`、`units-2-a6-select.png`、`display-6.png`、`english.png` 和 `date-1.png`。

另用 Tk 的 MENU 按钮和鼠标事件从头操作，85 帧与回放 PNG 逐像素一致。该窗口验证跳过了带亮度 RAM 初值的第一页测试及依赖其值的英文第一页画面对比，保留实际翻页操作。
