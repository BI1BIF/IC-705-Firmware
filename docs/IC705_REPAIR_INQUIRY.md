# 日版 IC-705 1.40：原板恢复核对单

先核对是否有办法恢复**同一块主板**：如果主程序无法启动、进不了 LCD 或 SD 菜单，维修方能不能恢复原厂程序，并保留原来的校准。这里只询问维修能力、适用板版和证据，不要求拆机或执行测试。

用户现在不用拆机、购买工具或升级。运行正常时可选提供 SET 里的「バージョン情報」一页；序列号后几位、呼号和网络信息不必发给项目。该页只供组件版本对照，匹配主板修订须另有维修记录或由维修方核实实物。[Icom 日版 1.40 公告](https://www.icom.co.jp/support/drivers/8603/)列了各组件版本及部分日版批次的旧版音频限制。

可转给购机渠道或维修方的日文询问：

> 国内向け IC-705 で、受信時のみ動作する第三者製の機能を本体に追加するための、メーカーが案内する SDK、拡張インターフェース、または正式な検証・導入手順はありますか。該当するものがあれば、対象機種・ファームウェア版と案内資料をお教えください。

> 国内向け IC-705（メイン CPU ファームウェア Ver.1.40）について、事前に修理の可否を確認したく、ご連絡しました。受信時の CW デコード機能を追加する非純正ファームウェアの研究を PC 上で行っていますが、無線機本体には書き込んでいません。純正ファームウェアの更新失敗時と、仮に非純正ファームウェアの書き込み後に起動不能になった場合について、それぞれ修理を受け付けるかお教えください。画面や microSD カードの更新メニューを使えない場合、基板交換ではなく、同一のメイン基板上で純正ファームウェアを復旧できますか。対応可能なメイン基板の品番・改版と、復旧時に工場調整値・個体固有データ・設定やメモリーを保持できるか（または再調整・消去となるか）を教えてください。復旧後に正常起動、受信音声、表示、WLAN の確認が可能かもお知らせいただけると助かります。現時点では可否の照会のみで、作業依頼ではありません。

拿到答复后按下面三项归档：

| 需要的证据 | 可以记录为通过的情况 |
| --- | --- |
| 对应日版主板 | 明确主板号及修订、所覆盖批次、基准组件版本。相同机型和相同的 1.40 显示不能代替板版。 |
| 原板数据 | 厂商可核实说明，或之后在另行授权的同版测试板上提供只读复读记录。主控 NOR 需覆盖完整阵列（引导、两个主程序位置、启动标记和共享数据）并记录影响启动的状态；两颗 EEPROM 分别核对，记录各自容量、两次读回的 SHA-256，以及已知启动区是否包含。[已验证](SAFETY_AND_RECOVERY.md#原厂设置备份能还原什么) SD 设置恢复没有覆盖这些启动区。FPGA Flash、WLAN 模块和其他组件说明是否涉及、如何确认未受影响。项目只保存必要的元数据，不公开整机转储。 |
| 独立恢复结果 | 在原厂主程序无法运行的条件下，同一板恢复原厂状态，重新开机后能核对接收、显示和板级校准。仅称可以送修、可以重置、或换板后能开机，均单独登记。 |

[原厂维修入口](https://www.icom.co.jp/support/personal/repair/)链接的[日文维修条款](https://www.icom.co.jp/uploads/support/personal/repair/Repair_Terms_and_Conditions.pdf)列出适用地区和机型。第 10 条排除厂家认定为不当改装的维修；第 16 条允许按需初始化、换件或安装不同固件，未承诺保留个体校准或同板恢复。旧版[原厂固件下载说明](https://www.icom.co.jp/support/drivers/7024/)提及写入失败可酌情走有偿维修，不能据此认为第三方固件故障一定受理。咨询模板没有发送。技术依据见[维修图核对](SAFETY_AND_RECOVERY.md#维修图核实主控时钟两套-flash-与日版适用范围)。

## 官方咨询渠道复核

2026-11-15。官方 [iUSE HF 支持](https://www.icom.co.jp/support/personal/iuse/)受理设备规格和故障咨询，本身不修机；实体维修经购买渠道或[纪之川维修中心](https://www.icom.co.jp/support/personal/repair/)。Icom [维修公告](https://www.icom.co.jp/news/4389/)也说明能否修视部件供应等条件；受理咨询不等于承诺恢复。法人 [OEM／个别开发表单](https://www.icom.co.jp/contact/oem/)是企业询问入口，未列 IC-705 扩展 SDK 或安装规程。安装和恢复仍需分开答复。

日版 [1.40 公告](https://www.icom.co.jp/support/drivers/8603/)的 `#31 / 31001001 起` 只说明该批次在所列版本条件下退回 1.24 或更早会导致音频异常。它不发布主板号或修订映射，也不能证明同板恢复；不为验证这一点而降级。若维修方要求完整序列号，请用户直接向官方渠道提供。项目只需要对方确认的适用主板号、修订及恢复条件。没有发送询问或上传设备信息。

补充对照：[维修手册的 2021 年 5 月 `B-8984J` 批次表](https://www.passion-radio.com/index.php?controller=attachment&id_attachment=787)列的是美国 `#12`、欧洲 `#13`、泰国 `#16`、英国 `#17`，不能拿这张表替日版 `#31` 确认同板。直接向 Icom 日本送修前要核对[维修条款](https://www.icom.co.jp/uploads/support/personal/repair/Repair_Terms_and_Conditions.pdf)的居住地与使用地条件；日版若在日本以外使用，优先由购机渠道确认可受理的维修方。只有报价或回答「可换板」时，原板恢复仍记为未满足。
